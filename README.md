# 海滨大道施工日志手机版

这是一个可部署到 GitHub Pages 的静态网页版本。手机打开网页后，只需选择照片并点击“一键生成施工日志”，浏览器会在本机处理图片并下载 Excel。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库。
2. 把本目录中的全部文件及 `vendor` 文件夹上传到仓库根目录。
3. 打开仓库的 `Settings` → `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/ (root)`，保存。
5. 等待 GitHub Pages 发布后，用手机浏览器打开 GitHub 给出的网页地址。

## 使用规则

- 模板固定使用 `template.xlsx`，网页和模板必须在同一目录。
- 图片时间识别顺序：EXIF 拍摄时间 → 文件名时间 → 文件修改时间。
- 上午：05:00–09:59；中午：10:00–14:59；下午：15:00 以后。
- 每个时段优先放本时段图片，每个时段最多 2 张；如果某个时段不足 2 张，会使用其他时段超过 2 张的未使用图片补位，不重复使用图片。
- 最终最多使用 6 张照片；未用于补位的多余照片会在完成提示中显示数量。
- 图片会在手机本地按模板比例居中裁切、缩放为 `1706×1279` 并以高质量 JPEG 写入，降低下载体积和手机内存占用，同时保持表格版式。
- 模板内原有的 5 张施工照片仍完整保留，仅做高质量压缩，方便手机快速加载。
- 第二行留空时自动更新模板日期；填写内容时可用 `{{日期}}` 插入当天日期。
- 图片不会上传到服务器。`JSZip 3.10.1` 和 `exifr 7.1.3` 已放入 `vendor` 目录，不依赖外部 CDN。

## 注意

GitHub Pages 只是静态网页托管，不会保存用户图片，也没有多人共享数据。生成的 Excel 需要从手机浏览器的下载文件中打开或转发。

本项目使用的第三方库及许可证位于 `vendor` 目录。
